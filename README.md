
## 🎯 Зачем этот проект

Я студент, и мне нужен был инструмент, который отвечает на простые вопросы:

- **Что скоро сдавать?** → ближайшие дедлайны
- **Где я отстаю?** → лекции, которые давно не смотрел
- **Насколько это плохо?** → чем выше приоритет предмета, тем раньше бьётся тревога

Это **не** заметки (заметки я пишу на бумажках). Это **не** файловое хранилище. Это только организация и контроль.

---

## ✨ Текущие возможности

| Функция | Статус |
|---|---|
| Семестры (создание, редактирование) | ✅ Готово |
| Предметы внутри семестров | 🚧 В работе |
| Компоненты предмета (лекции, лабы, практики) | 🚧 В работе |
| Отслеживание прогресса по лекциям | 🚧 В работе |
| Дедлайны (домашки, лабы, экзамены) | 🚧 В работе |
| Дашборд: ближайшие дедлайны + отставание | 🚧 В работе |
| Приоритет предметов (1-5) | 🚧 В работе |
